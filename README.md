# Huaqiang Video 🎬

> A Remotion production experiment for turning the Huaqiang melon story into a scripted, renderable short video.

[English](README.md) · [简体中文](README.zh-CN.md)

## Quick start

```bash
npm install
npm run start
```

Preview the composition in Remotion Studio and render using the scripts in `package.json`. The project keeps story beats, motion, and timing in code for **repeatable iteration**.

## Scope

This is a focused creative prototype, not a finished film or general video editor. See [`docs/`](docs/) for the story and storyboard. Existing rendered media is project material; confirm rights before redistribution.

## Roadmap & contribution
