# Contributing

Thanks for helping improve Huaqiang Video. This is a small Remotion production experiment, so focused changes are easiest to review.

1. Install the pinned dependencies with `npm ci`.
2. Preview with `npm run studio`.
3. Render the composition with `npm run render`.
4. Keep generated exports and local caches out of commits unless they are intentional deliverables.

For code changes, preserve the existing composition id and 1280×720 timeline unless the change explicitly updates the production format. For media or script changes, update the relevant storyboard or dialogue document as well.
