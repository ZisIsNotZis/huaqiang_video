## 四、场景与道具细节

### 瓜摊布局
- **整体形态**：长条形木质货架，沿人行道摆放，长度约3米，高度及腰
- **西瓜摆放**：
  - 前排：单层平铺，约10-12个西瓜，瓜蒂朝内，便于顾客挑选
  - 后排：堆叠2-3层，数量更多
  - 左侧有几个切开的西瓜样品，露出红色瓜瓤招揽顾客
- **其他水果**：瓜摊右侧摆放香蕉、草莓等，有纸板写着"香草莓特甜5元2斤"
- **称重区**：瓜摊中间位置放一杆老式盘秤，是摊主的"作案工具"
- **工具区**：秤旁边放着一把长刃西瓜刀，刀身宽大，刀刃锋利
- **座椅**：瓜摊内侧靠后位置放一把简易木椅，是摊主休息坐的

### 背景环境
- **左侧店铺**："工农路干洗店"红色白字招牌
- **后方店铺**：写有"冻食"字样的店铺、理发店
- **街道元素**：行道树（国槐）、自行车停放区、来往车辆（红色桑塔纳、银色小货车、红色出租车）
- **时代特征**：90年代末街景，行人穿着朴素，车辆都是老款，充满市井气息

### 关键道具
1. **黑色踏板摩托车**：刘华强的交通工具，车牌号冀ZE7168
2. **老式盘秤+吸铁石**：缺斤短两的核心道具
3. **西瓜刀**：长约30厘米，宽刃，木柄，最终成为凶器
4. **西瓜**：绿皮深纹，个头中等，15斤是虚报，实际约10斤
5. **香烟**：郝哥全程叼着烟，是他痞气形象的重要组成
