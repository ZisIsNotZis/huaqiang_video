## 五、人物站位与空间关系

### 对峙阶段（对话期）
```
          【马路】
            ↓
  ┌───────────────────┐
  │  刘华强（站）    │ ← 人行道
  └───────────────────┘
            ↓
  ===================== 瓜摊台面
  西瓜  秤  西瓜刀  西瓜
  =====================
            ↑
  ┌───────────────────┐
  │ 郝哥（站中间）    │
  │ 同伙A   同伙B     │ ← 瓜摊内侧
  └───────────────────┘
```

### 升级阶段（入座后）
```
  ===================== 瓜摊台面
  西瓜  秤  西瓜刀  西瓜
  =====================
        ↗
  刘华强（坐下）
  ───────────────────
    郝哥（站对面）
        ↗
      同伙A  同伙B（被挡住）
```

刘华强入座后，巧妙利用椅子和瓜摊的空间卡位，让郝哥身后的两个同伙无法从两侧包抄，只能从正面过来，大大降低了自己的风险。
