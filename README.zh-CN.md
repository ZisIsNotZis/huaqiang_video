# 华强视频 🎬

> 一个 Remotion 制作实验，把“华强买瓜”故事做成脚本化、可渲染的短片。

[English](README.md) · [简体中文](README.zh-CN.md)

## 快速开始

```bash
npm install
npm run start
```

在 Remotion Studio 中预览构图，再按 `package.json` 中的脚本渲染。项目把故事节拍、动效和时间轴写入代码，支持**可重复迭代**。

这是聚焦的创意原型，不是成片或通用视频编辑器；故事和分镜见 [`docs/`](docs/)。重新分发素材前请确认版权。后续会补充渲染预设、素材替换和发布检查清单。欢迎附前后对比与渲染命令贡献。许可证：AGPL-3.0-only，见 [`LICENSE`](LICENSE)。
