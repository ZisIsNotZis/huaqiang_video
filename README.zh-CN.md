# 华强买瓜 · Huaqiang Melon 🎬

> 一个小型 Remotion 构图实验，把“华强买瓜”故事做成脚本化、可渲染的短片。

[English](README.md) · [简体中文](README.zh-CN.md)

## 快速开始

需要 Node.js 20+ 和 npm。

```bash
npm install
npm run start
```

在 Remotion Studio 中预览 `HuaqiangMelon`，用下列命令渲染已记录的预设：

```bash
npm run render
```

当前构图为 1280×720、30 fps；证据和限制见 [`docs/project-status.md`](docs/project-status.md)，故事和分镜见 [`docs/`](docs/)。

这是创意原型，不是成片或通用视频编辑器。故事、音频和视频属于项目素材，重新分发前请确认版权和肖像授权。本仓库不包含新的 Bilibili 上传或 arXiv 论文。
